1. Introduction

TEO-5 Editor puts the whole TEO-5 on your screen. Every knob and button on the panel matches a control on the synth and works both ways: turn a knob on the screen and the TEO-5 follows; turn a knob on the TEO-5 and the screen follows. Around the panel are drawers that slide out from the side cheeks for the things the synth's own panel can only reach through menus: a librarian, the full 16-slot modulation matrix, a step-sequence editor, and the GLOBAL and PROGRAM settings.

The editor makes no sound itself. It talks to the TEO-5 over MIDI (NRPN messages for the controls, SysEx for whole programs and settings). It comes in three forms that all work the same way:

  • Standalone app (TEO-5 Editor.app): the simplest way to edit and organise sounds.
  • VST3 and Audio Unit plug-ins: load the editor on a MIDI track in your DAW, so each project remembers its TEO-5 sound and sends it back to the synth when the project opens.

What the editor never does without asking

Loading programs, turning knobs and editing sequences only change the TEO-5's edit buffer (the sound you're playing). Nothing is stored in the synth's memory until you choose to write it, and every write names the exact location and asks first. Factory banks can never be overwritten.

2. Installing

  1. Unzip TEO-5-Editor-{{VERSION}}-macOS-Universal.zip.
  2. Open Terminal, type bash followed by a space, drag install.command from the unzipped folder into the Terminal window, and press Return.
  3. The installer puts the files here, removes older copies, clears the macOS download block and checks that the plug-in loads:
    FileInstalled to
    TEO-5 Editor.vst3/Library/Audio/Plug-Ins/VST3
    TEO-5 Editor.component/Library/Audio/Plug-Ins/Components (Audio Unit)
    TEO-5 Editor.app/Applications
    It may ask for your Mac password if one of those folders needs administrator rights.
  4. When it says "OK: the VST3 loads", make your DAW rescan its plug-ins. In Ableton Live: Settings → Plug-Ins, turn on Use VST3 Plug-In System Folders (and Use Audio Units if you want the AU), then hold Option and click Rescan. If the DAW was open, quit and reopen it.
The download isn't notarized by Apple, so double-clicking install.command may be blocked. Running it from Terminal as above avoids that. Copying the plug-ins by hand keeps the download block on them, and DAWs then skip them silently; run the installer instead.

3. Connecting to the TEO-5

Settings on the TEO-5

Press GLOBAL on the TEO-5 and set:

  • MIDI Param Send = NRPN and MIDI Param Receive = NRPN
  • MIDI SysEx = On, and MIDI SysEx Cable = the connection you use (USB or MIDI)
  • MIDI Program Send = On (the TEO-5 only answers requests for programs and settings when it's on)

Once the editor can reach the synth, the Set up TEO-5… button in the MIDI drawer can set all of these for you.

Settings in the editor

  1. Click the MIDI tab on the right-hand cheek.
  2. Choose the TEO-5 under Input and Output, and the MIDI channel.
  3. Click Find TEO-5. The line under the buttons should report the TEO-5 and its OS version.
  4. Turn a knob on the TEO-5: the matching knob on the screen moves. Turn CUTOFF on the screen: the synth follows.

The editor opens the MIDI ports itself rather than relying on the DAW, because many DAWs don't pass SysEx to plug-ins. Your port choice is saved with the DAW project (or with the standalone app).

Sequencer and arpeggiator clock

When the TEO-5's MIDI Clock mode is In, In Thru or In No S/S, its arpeggiator and sequencer only run while clock arrives. In Ableton Live, open Settings → Link, Tempo & MIDI and turn on Sync for the TEO-5's MIDI output. In No S/S (tempo from Live, Live's Start/Stop ignored) works best with the editor: the sequencer's PLAY button then decides whether the sequence runs, and it follows Live's tempo.

4. The front panel

{{shot panel|The front panel. Drawer tabs: LIBRARY, MOD MATRIX and SEQUENCER on the left cheek; GLOBAL, PROGRAM and MIDI on the right.|0|1|0|1|100%}}

The panel follows the TEO-5's own layout section by section, so everything is where you expect it. The TEO-5 User's Guide explains what each control does to the sound; this chapter explains how the controls behave on screen.

The panel guide (?)

The round ? button at the top left of the panel, left of MASTER, opens a guide to the front panel right in the editor: knobs and buttons, the display, choosing programs, assigning modulation with a right-click, the mod matrix, the drawers and the shortcuts. Close it with the ? again, CLOSE or Esc; opening a drawer closes it too.

{{shot guide|The front panel guide, opened with the ? at the top left.|0|1|0|1|100%}}

Knobs

  • Drag up or down to turn a knob. The whole range takes about 220 pixels.
  • Hold Shift while dragging or scrolling for fine adjustment.
  • The mouse wheel or trackpad also turns knobs.
  • Double-click a knob to put it back to the value stored in the loaded program (not a factory default).
  • Right-click a knob for modulation options (chapter 6). Right-clicking never changes a value.

Buttons and LEDs

Buttons toggle on a click and light red when on. Where the TEO-5 uses a button to step through choices (LFO shape, LFO 1/2, envelope destinations, arpeggiator octave and repeat), the LEDs next to it show the current choice.

The display (OLED)

  • The home page shows the program name, with tempo, clock divide, arpeggiator and effect around it, like the synth. When the TEO-5 follows an external clock, it shows EXT BPM with the DAW's tempo.
  • While you turn a control it shows the control's name and its new value, followed in smaller, dimmer text by the value stored in the program, in parentheses. That tells you how far you've moved from the saved sound.
  • The star left of the name is the library's favourite mark for this program (dim if the program isn't in the library).
  • Double-click the display to rename the program.

Special buttons

  • TAP TEMPO: tap at least twice in time; the editor averages the last taps and sets BPM. A pause of two seconds starts a new count.
  • LIBRARY: opens the Library drawer (lit while open).
  • PANIC: stops hung notes. Sends All Sound Off, All Notes Off, Reset All Controllers and a note-off for every note. It also ends any SysEx message the synth is still waiting to finish. The program, sequencer and arpeggiator are left alone.
  • INIT: loads the TEO-5's Basic Program into the edit buffer, a clean starting point for a new sound. Nothing is written to memory.

5. Choosing, comparing and writing programs

Choosing a program

  • Program buttons 1–16 choose a program in the current bank. The display shows bank and program (banks 10–16 appear as A–G).
  • BANK: press it (it lights), then a program button chooses the bank; press BANK again to go back to choosing programs.
  • FACTORY switches between the User banks and the Factory banks.
  • BANK < > and PATCH < > under the display step through banks and programs.
  • With no drawer open, the arrow keys do the same: Left/Right step the program, Up/Down the bank.

Each change sends Bank Select and Program Change to the TEO-5 and then reads the new program, so the panel, mod matrix and sequencer all show the sound you're hearing. Program changes and knob moves made on the synth follow too. Loading the Basic Program on the synth (GLOBAL > Basic Program) sends nothing over MIDI, so the panel doesn't see it; use INIT on the editor's panel instead.

COMPARE

Switches between your edited sound and the program as it was loaded, like COMPARE on the synth. Press it again to return to your edit.

REVERT

The button under MOD. Drops all your edits (knobs, mod matrix, sequence) and goes back to the program as it was loaded, or as last written with WRITE. It sends that program to the TEO-5's edit buffer and never writes to memory. If you have edits, it asks first, because they can't be brought back. Hover over it for a reminder.

WRITE

Saves the current sound. WRITE opens the library with the panel's program selected, and a Save program pop-up appears over the panel:

{{shot library-write|Saving with WRITE: the slot chosen in the library is outlined in amber, and its program is in the edit buffer to audition.|0|1|0|1|100%}}
  • Choose where: click a slot in a TEO-5 User bank or in one of your banks (MY BANKS). Every bank in MY BANKS ends with an Empty slot for a new program. Factory banks can't be chosen. If the panel's program isn't in a User bank or one of your banks, User 1 slot 01 is chosen to start with.
  • Audition: the program stored in the chosen slot goes into the TEO-5's edit buffer. Play your MIDI controller or the synth's keys to hear the sound you would replace. The panel keeps showing your edit.
  • Confirm saves. Into a TEO-5 User slot it's written to the synth's memory (and the library); into MY BANKS it's kept in the library only. The library closes and the panel shows the saved program.
  • Cancel (or LIBRARY, or Esc) puts your edit back in the edit buffer and closes the library.

Until you save, all edits live only in the edit buffer, and changing program discards them (the DAW project can still keep them). The OLED shows EDITED in red under the program name while the sound differs from the stored program.

6. Modulation from the panel (right-click)

Right-click any knob or button that the TEO-5 can modulate (for example CUTOFF, the LFO rates and amounts, effect and reverb controls, oscillator frequencies, envelope stages, or the OSC 1, SUB, OSC 2 and NOISE levels). The menu offers:

  • Modulate <control> from ▸ every modulation source (LFOs, envelopes, velocity, mod wheel, pressure, random and so on).
  • Already modulated by: the mod slots that already route to this control; choose one to jump to it.
  • For the controls of a source (LFO, ENV 1, ENV 2, OSC 2, NOISE): Send <source> to ▸ every destination, grouped by section.

Choosing an entry fills the first free mod slot, opens the Mod Matrix drawer and outlines the new slot in amber. The new slot starts with an amount of zero, so nothing changes until you drag its amount. The outline goes away when you edit another slot or close the drawer.

{{shot modmatrix-assign|A slot added from the right-click menu, outlined and ready for its amount.|0|0.327|0|1|66%}}

If all 16 slots are in use, the menu says so. Controls that the TEO-5 can't modulate have no menu.

7. The Library drawer

Open it with the LIBRARY tab on the left cheek or the LIBRARY button on the panel.

{{shot library|The library: TEO-5 banks on the left, your own banks (MY BANKS) on the right.|0.009|0.5375|0|1|100%}}

Two panes

  • TEO-5 (left): copies of the synth's User and Factory banks, fetched from the TEO-5. A User bank always has 16 slots, matching the synth.
  • MY BANKS (right): your own collections: imported .syx files and banks you make. They hold any number of programs.

Banks start collapsed; click the arrow to open one. Drag a bank's name to reorder banks within a pane. Double-click a bank's name to rename it. Every bank in MY BANKS ends with an Empty slot, so there's always room to save or drop one more program. The ? left of LIBRARY opens a guide to the library.

Buttons

FetchReads from the TEO-5: the edit buffer, the current bank, or all User/Factory banks (with a progress bar). Fetching a bank again replaces the earlier copy.
ImportAdds .syx files (single programs or banks). You can also drop files from Finder.
Save all changesWrites every NOT SENT program in your TEO-5 User banks to the synth. It lists what will be overwritten on the TEO-5 (for example U1-05: "Brass Hit" is overwritten by "Pulse Ping") and asks you to Confirm or Cancel. The NOT SENT marks go once the programs are sent.
New BankAsks for a name and makes a new empty bank in MY BANKS.
Undo / RedoUndoes any library change (also Cmd+Z / Shift+Cmd+Z). The status line names what was undone.
TEO-5 → LibraryFetches all 16 User banks (warns first if the library has changes not yet sent).
Library → TEO-5Writes the library's User banks to the synth: only the changed slots, or every slot. It lists what will be written and asks first.
Search / FavouritesSearch matches names, sources and tags; tag:pad searches tags only. Favourites shows only starred programs.

Programs

  • Click a program to load it into the TEO-5's edit buffer and hear it. (Shift-click and Cmd-click only select.)
  • The icons on each row: star (favourite), export .syx, rename, delete. Factory programs show only the star and export.
  • Right-click a program for more: load, write, rename, tags, favourite, copy, paste, duplicate, export, delete. Write to TEO-5 memory saves that program the same way as WRITE on the panel: pick a slot, audition, then Confirm. The library stays open afterwards. Right-click a bank to rename, import, export, send it to the TEO-5, fetch it again, or delete it.
  • Tags appear on the right of the row; give a program several tags (for example pad, ambient).
  • Cmd+C, Cmd+V and Delete work on the selection. Every delete asks first.

Dragging

  • Dropping a program onto another program in the same TEO-5 User banks, or within one of your banks, swaps them.
  • Dragging between two of your banks moves the program; dragging out of a Factory bank copies it.
  • Hold Option while dragging to copy instead of moving.

NOT SENT and Empty

Changes to the TEO-5 User banks in the library aren't on the synth until you send them. A slot whose program differs from what the TEO-5 holds there is marked NOT SENT in red, and the bank header counts them. The library remembers what the synth has in each slot (from the last fetch, send or WRITE), so putting programs back where they were, or Undo, clears the mark again. Deleting a program from a User bank leaves an Empty slot; when you send the bank, the editor writes the TEO-5's Basic Program there. Use Save all changes, Library → TEO-5 or Send bank to send. If you close the library with the LIBRARY button while changes aren't sent, it asks whether to send them first (this writes the patches to the TEO-5's memory).

Factory banks are read-only: they can't be renamed, deleted, pasted into or written to.

Where the library is kept

In ~/Documents/TEO5Editor/Library: library.json holds the banks, names, tags and favourites, and programs/ holds each program as a standard .syx file that other SysEx librarians can read. Back up this folder to keep your library safe.

8. The Mod Matrix drawer

Open it with the MOD MATRIX tab on the left cheek or the MOD button on the panel. It shows all 16 of the program's modulation slots at once.

{{shot modmatrix|All 16 mod slots: LED, source, amount and destination.|0|0.327|0|1|66%}}
  • Source and Destination: choose from the drop-downs. The destinations are grouped by section (oscillators, filter, effects, LFOs, envelopes, voice, and other slots' amounts).
  • Amount: drag the bar left or right (from −127 to +127, zero in the centre), or use the mouse wheel. Double-click restores the amount stored in the program.
  • LED: click to turn a slot off and on again. Off sets the amount to zero and remembers it (the slot shows OFF with a dashed outline). The TEO-5 has no per-slot switch, so a slot written while off is stored with zero.
  • Right-click a slot or its amount: Clear amount, Clear slot, or Restore slot to patch default (its stored source, amount and destination).
  • Clear all (top right) empties all 16 slots; Revert puts all 16 back as stored in the program. Each is one Undo step.
  • Undo / Redo step through your changes in the drawer; the hint line says what was undone. The history starts over when you change program.

The number of active slots is at the far right of the header. Changes are sent to the edit buffer as you make them.

9. The Sequencer drawer

The TEO-5 stores a step sequence in every program: up to 64 steps, each playing up to five notes. Open the editor with the SEQUENCER tab on the left cheek. It shows the sequence of the sound in the edit buffer and changes it there; nothing is stored until you WRITE. The ? button left of the title opens a full guide.

{{shot sequencer|The sequencer: two blocks of 32 steps with five note lanes, then the step panel, transpose and keyboard.|0.009|0.698|0|1|100%}}

At the top

  • Bank drop-down and ◀ PATCH ▶: choose a TEO-5 bank (User or Factory) or one of your library banks, then step through its programs. PATCH stays within the chosen bank.
  • LENGTH − / +: the number of steps (1–64). You can also drag along the step numbers.
  • PLAY: starts and stops the TEO-5's sequencer. Changing program (bank, patch or FACTORY) stops it and turns PLAY off. With the synth's clock on In No S/S, the sequence runs while Live plays; PLAY turns amber and says Waiting for Live until then. Every Live start restarts the sequence at step 1.
  • REC: step entry (see Recording below). STEP shows the current step and the length.
  • From TEO-5 reads the sequence on the synth (also done each time the drawer opens). Reset puts back the sequence stored in the program. Undo / Redo step through your changes.

Steps

  • A note has a blue bar under it; a green bar is a note held (tied) from the step before; a hatched step is a REST.
  • Click a step's number to select it and hear its notes while you hold the mouse. Click a note to select just that note. Shift-click selects a range; Cmd-click adds or removes steps.
  • Right-click steps to Copy, Paste (also into another program), Clear step or Clear all sequencer data.
  • While the sequence plays, the lit step number follows the playhead.

Step panel, transpose and keyboard

  • PLAY / REST / TIE set what the selected step does. Each note has a velocity slider (you hear it as you drag), MUTE and × (remove).
  • Transpose moves notes by a semitone or an octave, for all steps or only the selected ones. It's off while the sequence plays.
  • Keyboard: click a key to add that note to the selected step (or replace the selected note). OCT − / OCT + shift the range.

Recording

  • Press REC (or RECORD on the front panel, which opens the drawer with REC on). The amber box marks the step being recorded; each key you play goes in and the box moves on. Keys can come from the on-screen keyboard, the DAW track, or the TEO-5's own keys.
  • CHORD stacks keys on one step (up to five); NEXT moves on. REST and TIE enter a rest or a held step. ◀ BACK / NEXT ▶ move without entering anything.
  • You can record while the sequence plays; notes the sequencer itself plays are recognised and not entered.
  • Recording with the TEO-5's own RECORD button also works: the editor clears the sequence when RECORD goes on (as the synth starts again from step 1) and fills in the steps live as you play. The whole pass is one undo step. The editor's REC and the synth's RECORD never run together.
The TEO-5 stops its sequencer whenever it receives a new edit buffer. So while the sequence plays, the editor sends your changes as the loop starts over and restarts playback at step 1; you hear them from the next pass.

10. The GLOBAL drawer

The GLOBAL button on the panel or the GLOBAL tab on the right cheek opens the TEO-5's global settings, in the same order as the synth's GLOBAL menu: tuning, playing (local control, mono/stereo, pot mode, pedals, aftertouch and velocity curves, alternative tunings), MIDI (channel, clock mode and cables, parameter send and receive, SysEx, program send) and more.

{{shot global|The GLOBAL drawer reads the synth's settings each time it opens.|0.7675|0.9875|0|1|46%}}
  • The drawer reads the settings from the TEO-5 each time it opens (Read from TEO-5 reads them again).
  • Each change is sent to the synth at once. Settings that could cut the connection (MIDI channel, parameter receive, SysEx and so on) ask first.
  • Global settings belong to the synth, not to a program or a DAW project.

11. The PROGRAM drawer

The PROGRAM button or tab lists the program settings that have no knob on the panel, grouped by section: oscillator key tracking, detune, pulse widths and glide, oscillator and noise levels, noise type, filter key amount and band-pass, envelope options, voice settings, tunings and more.

{{shot program|The PROGRAM drawer: settings without a panel knob.|0.7675|0.9875|0|1|46%}}
  • Drag a value bar, choose from a drop-down or tick a box. Changes go to the edit buffer at once and are kept when you WRITE.
  • Tick Also list settings that have a panel knob at the bottom to see every program setting in one list.

14. Using TEO-5 Editor in a DAW

  • Add TEO-5 Editor (VST3 or AU) to a MIDI track as an instrument. Play the TEO-5 from that track with Play the TEO-5 from the DAW track on, or play the synth directly.
  • Projects remember the sound. When you save, the project stores the program, including its sequence. When you open the project again, the editor sends that sound to the TEO-5's edit buffer about half a second later (it never writes memory).
  • A new instance on a fresh track opens on User bank 1, program 01: it selects that program on the TEO-5 and reads it into the panel.
  • Live's transport and the sequencer: with PLAY on in the sequencer, each Live start restarts the sequence at step 1 and Live's stop stops it.
  • Recording the sequencer into Live: turn on MIDI Arp Notes in the GLOBAL drawer, make a MIDI track with MIDI From = the TEO-5, MIDI To = No Output and Monitor Off, arm it and record while the sequence plays.

15. Troubleshooting

The synth doesn't respond to the editor

  • Click Send test note in the MIDI drawer. If you don't hear middle C, check the Output port and channel. The monitor shows OUT (no port!) when no output is chosen.
  • Click Find TEO-5. The monitor should show a SysEx message going out and one coming back. If nothing comes back, check the Input port and the TEO-5's MIDI SysEx and SysEx Cable settings.
  • Knobs on the synth don't move the screen: set the TEO-5's MIDI Param Send to NRPN.
  • Programs or settings don't load: set the TEO-5's MIDI Program Send to On. It can switch off after a power cycle.

The sequencer or arpeggiator doesn't run

With the TEO-5's clock mode on In, In Thru or In No S/S, it needs MIDI clock. Turn on Sync for the TEO-5's output in your DAW (chapter 3). The sequencer drawer warns in amber when the clock mode is set so that Live's transport would start it.

Stuck notes

Press PANIC.

The TEO-5 shows "Receiving SysEx" and ignores the editor

The synth is waiting for the end of a SysEx message and ignores everything else until it comes. Press PANIC: it sends the end. The editor also sends it every time it connects to the synth. If it keeps happening, the file ~/Library/TEO5Editor/midi-log.txt records every message the editor sent and received, with the time.

The plug-in doesn't show up in the DAW

  • Run install.command again. If it ends with "OK: the VST3 loads", the plug-in is fine and the DAW only needs to rescan.
  • Ableton Live: Settings → Plug-Ins, turn on Use VST3 Plug-In System Folders (and Use Audio Units for the AU), hold Option and click Rescan.
  • Bitwig: Settings → Plug-ins → Rescan; re-enable TEO-5 Editor if it's listed as failed or blocked.
